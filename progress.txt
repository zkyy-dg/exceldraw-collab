## Codebase Patterns
- @hono/node-server 1.19+ does NOT export `upgradeWebSocket`. Use `createAdaptorServer({ fetch })` to get a Node.js http.Server, then add `server.on("upgrade", ...)` with ws.WebSocketServer({ noServer: true })
- Excalidraw does NOT export `PointerUpdate` type. Define locally: `{ x: number; y: number; tool: "pointer" | "laser"; pressure: number; pointerType: string }`
- `window.EXCALIDRAW_ASSET_PATH` is not in Excalidraw's type declarations. Use `declare global { interface Window { EXCALIDRAW_ASSET_PATH: string } }` to avoid TS errors
- Excalidraw's @radix-ui/react-tabs has peer dep warnings for React 19 — harmless, ignore
- pnpm requires `onlyBuiltDependencies` in root package.json to compile native modules like better-sqlite3
- The server runs on PORT env var (default 3100 in this environment, default 3001 in code)
- `tsconfig.base.json` at root with `"moduleResolution": "bundler"` is shared by both packages
